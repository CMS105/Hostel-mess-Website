# 🍽️ MESSMATE
### Smart Hostel Mess Management & Sustainability Platform

**Tagline: Every Meal Matters. Every Voice Counts.**

Better food. Better hygiene. Less waste. A smarter hostel dining experience.

## 🌟 About the Project

MESSMATE is a browser-based hostel mess management platform that connects students with mess administrators. It helps improve food quality, collect transparent student feedback, monitor cleanliness and reduce food wastage through data-driven insights.

Our goal is to transform traditional hostel mess management into a smarter, more transparent and sustainable system.

## 🚀 Key Features

### 🎓 Student Portal
- **Weekly Menu Calendar:** Explore a complete 7-day South Indian hostel menu covering breakfast, lunch, snacks and dinner.
- **Smart Meal Rating:** Rate meals and view live average ratings with total vote counts.
- **Future Meal Protection:** Prevent students from rating meals before their serving time.
- **Smart Feedback:** Low ratings trigger feedback options to identify food quality issues.
- **Alternative Food Hub:** Vote for alternative dishes and request menu changes.
- **Hygiene Monitoring:** Rate dining halls, tables, drinking water areas, kitchens and washrooms.
- **Gamification:** Earn participation points, unlock achievement levels and track contributions.

### 👨‍🍳 Admin Portal
- **Operations Dashboard:** View student participation, meal satisfaction, cleanliness and food waste.
- **Weekly Menu Management:** Add, edit and publish menus for all seven days.
- **Food Analytics:** Identify best-rated and lowest-rated dishes.
- **Anonymous Feedback:** Review student feedback without exposing personal identities.
- **Food Waste Intelligence:** Record prepared, served and wasted food quantities.
- **Hygiene Management:** Monitor cleanliness inspections and resolve complaints.
- **Smart Recommendations:** Get rule-based suggestions to improve food quality and reduce waste.
- **Reports & CSV Export:** Export ratings, waste records, feedback and hygiene reports.

## 💡 What Makes MESSMATE Different?

- Student-driven food quality improvement.

## ⚡ Run Locally

```bash
# Clone the repository
git clone https://github.com/YOUR-USERNAME/Hostel-mess-Website.git

# Open project folder
cd Hostel-mess-Website

# Install dependencies
npm install

# Start development server
npm run dev
```

Open the local URL displayed in your terminal (usually `http://localhost:5173`).
